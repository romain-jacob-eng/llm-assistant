# LLM Assistant — Anthropic API & Text Analysis

## Overview
A command-line assistant powered by the Anthropic API (Claude) that performs three core NLP tasks on any input text: sentiment analysis, one-sentence summarization, and keyword extraction. Demonstrates real-world API integration with clean function separation across a modular Python structure.

## Technologies
Python, Anthropic Python SDK, python-dotenv

## How to run
python assistant.py
